# SIMS Doctor v1.0.0 Sprint2-2 Foundation

This release adds the executable reception foundation without adding diagnosis logic.

## GitHub update method

Extract this ZIP and overwrite the existing repository files. Do not delete the repository first. Existing assets not contained in the ZIP should be reviewed before removal.

## Required action after update

Run `pytest -q` and `python tests/contract/validate_fixtures.py`.

## Remaining compatibility gate

Compare the provisional request schema with one real `SIMS_DOCTOR_SINGLE_CASE_REQUEST_V1` JSON generated by SBM.
