# Composite Diagnosis

Composite Diagnosis integrates all specialist assessments and determines the final Doctor
diagnosis.

It combines:

- Vital Score
- Improvement Failure
- Long-Term Degradation
- CTR Opportunity
- Position Opportunity
- Intent Drift
- Freshness Decay
- Cannibalization
- Content Integrity
- Competition Resilience

Safety rules take precedence over weighted scoring.
Doctor still does not execute treatment.
