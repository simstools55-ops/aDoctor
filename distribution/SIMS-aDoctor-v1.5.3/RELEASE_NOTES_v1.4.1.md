# aDoctor v1.4.1

## Product UI naming consolidation

- User-facing product name is now **aDoctor**.
- User-facing orchestration name is **SIMS Manager**.
- User-facing managed-target terminology is standardized on **site** rather than blog where applicable.
- Internal identifiers and contracts remain unchanged, including `SIMS_DOCTOR_*`, repository names, schema titles, `source_product`, Case IDs, and Shared v3.5.0 baseline.
- No diagnostic behavior change.
