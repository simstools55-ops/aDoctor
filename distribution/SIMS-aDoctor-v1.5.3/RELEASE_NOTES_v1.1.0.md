# SIMS Doctor v1.1.0 Release Notes

## Theme
Treatment Plan UX / Blog Primary Doctor

## Changes
- Doctorコメントを回答先頭へ追加
- 診断確信度の日本語ラベルと判断基準を正式化
- 今日・処置後・次回のToDoを明示
- 今回はやらないことを必須化
- サイト全体要因、競合、低サンプル等に応じた実行可能なアドバイス
- Writer / Creator / Mergeへのコピー専用依頼文
- 通常利用者向けDoctor JSON非表示を維持
- SBMへ登録するのは専門製品の処置結果JSONのみ

診断エンジンの主要ロジックや安全境界は変更していません。
