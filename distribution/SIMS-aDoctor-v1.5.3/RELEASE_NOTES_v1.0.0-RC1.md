# SIMS Doctor v1.0.0-RC1

SIMS Doctor v1.0.0 release candidate.

## Included
- single-case diagnostic workflow
- diagnostic Medical Record SSOT
- 365-day data architecture
- specialist diagnosis engines
- improvement failure and long-term degradation diagnosis
- CTR, position, intent, freshness, and cannibalization diagnosis
- Composite Diagnosis
- Treatment Recommendation and referrals
- user and system Doctor Reports
- Explainable Diagnosis
- full contract, unit, integration, regression, and release integrity tests

Doctor determines diagnosis and treatment policy. It does not execute treatment.

RC1 is intended for repository integration and real-case acceptance testing before the
v1.0.0 production baseline.
