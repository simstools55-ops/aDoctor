# Vital Signs Layer

All health-oriented Vital Signs use a 0–100 score where a higher score is healthier.

This avoids the ambiguity of mixing “competition pressure 90 = bad” with
“CTR health 90 = good”. The competition-related sign is therefore named
`COMPETITION_RESILIENCE`.

The initial normal ranges are classification ranges, not yet calibrated SEO formulas.
Formula calibration requires real Doctor cases and must be versioned.
