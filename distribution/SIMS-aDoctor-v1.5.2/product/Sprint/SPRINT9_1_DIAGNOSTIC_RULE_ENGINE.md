# Sprint9.1 — Diagnostic Rule Engine

## Included

- declarative diagnostic rule contract
- rule registry
- rule condition operators
- multiple Medical Record data sources
- deterministic evaluation order
- confidence adjustment
- low-sample penalty
- same-diagnosis deduplication
- mutual-exclusion conflict resolution
- explainable diagnosis candidates
- Medical Record evaluation history
- idempotent evaluation event
- contract, unit, integration, and regression tests

## Excluded

- replacement of existing Differential Diagnosis
- direct Final Diagnosis generation
- treatment or referral generation
- machine learning
- graphical rule editor
