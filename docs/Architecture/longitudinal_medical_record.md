# Longitudinal Medical Record Analysis

The longitudinal profile summarizes repeated diagnoses and treatment responses for one article.

## Profile states

- Insufficient History
- Stable
- Recurrent
- Chronic
- Treatment Responsive
- Treatment Resistant
- Recovering

## Follow-up priority

- Low
- Medium
- High
- Urgent

The profile supports prioritization and future batch diagnosis. It does not replace the
latest Final Diagnosis.
