# Sprint3.1 — Clinical Knowledge Base Foundation

## Goal

Create a stable declarative boundary for Observation, Evidence, Vital Signs,
Findings, and medical-record events.

## Included

- CKB manifest
- Observation type registry
- Evidence code registry
- Vital Sign registry and normal ranges
- Finding code and severity registry
- Medical-record event registry
- Runtime loader and structural validation
- Clinical data models
- Unit tests

## Excluded

- Search Console acquisition
- SERP acquisition
- scoring formulas
- evidence extraction
- finding generation
- differential and final diagnosis
- referrals
