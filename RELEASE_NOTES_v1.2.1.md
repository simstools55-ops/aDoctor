# SIMS Article Doctor v1.2.1

## Product rename
- Formal product name changed from `SIMS Doctor` to `SIMS Article Doctor`.
- Role is explicitly limited to single-article precision diagnosis.
- Site-wide diagnosis belongs to `SIMS Site Doctor`.
- Treatment execution remains in Writer / Creator / Merge under SBM orchestration.

## Compatibility
- `DOCTOR` product code and `SIMS_DOCTOR_*` contracts remain unchanged.
- Existing CaseID / RequestID / ArticleID contracts remain unchanged.
- This release normalizes the formal version to three-part semantic versioning: `1.2.1`.
